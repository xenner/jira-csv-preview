CSV Preview for Jira

Preview CSV and TSV attachments without downloading them.

Appearance

Reading

The viewer automatically detects the delimiter (comma, semicolon, tab or pipe) and the encoding. You can also change them in the toolbar.

Jira sites

The extension works with Jira Cloud by default. For Jira Data Center or a custom domain, add the base URL and grant access only to that site.

*.atlassian.net *.atlassian.com *.jira.com

After adding or removing a site, reload the Jira tabs you already have open.

Downloads

Some Jira installations serve attachments from an external domain (for example, an S3 bucket). If the preview fails with a permission warning, enable this option.

Shortcuts

Ctrl + Shift + Y
Open CSV attachments for this issue
Esc
Close the viewer or the open dialog
Ctrl / ⌘ + F
Search within the CSV
Ctrl / ⌘ + C
Copy the selected cell

You can change the shortcut at chrome://extensions/shortcuts.

Privacy

The extension does not collect data, use analytics, or send anything outside your browser. It only queries the attachment list of the issue you are viewing and downloads the file you choose to preview, using your Jira session.
